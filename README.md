# Learning Rust

This is a guide for learning Rust, including basic commands for creating, compiling, and running projects.

## Steps to Work with Rust

### 1. Create a New Cargo Project
To create a new Rust project managed by Cargo, run:
```bash
cargo new project_name
```
Replace `project_name` with the desired name of your project.

### 2. Compile a Single Rust File
To compile a single `.rs` file, use:
```bash
rustc filename.rs
```
Replace `filename.rs` with the name of the file you want to compile.

### 3. Run a Compiled File
After compiling a file, you can run it using:
```bash
./filename
```
Replace `filename` with the compiled file name (without `.rs`).

### 4. Run a Project from Cargo
If you are working in a Cargo project, use the following command to compile and run your application:
```bash
cargo run
```
